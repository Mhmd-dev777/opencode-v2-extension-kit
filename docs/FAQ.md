# الأسئلة الشائعة

## هل يثبت السكربت OpenCode؟
لا. إذا لم يكن OpenCode v2 مثبتاً، يعرض خطأ ويطلب تثبيته أولاً.

## لماذا لا يثبت كل الأسماء؟
لأن بعض الأسماء لا تملك مصدراً عاماً موثوقاً، وبعضها يعلن اعتماد V1. تثبيت حزمة مشابهة بالاسم أخطر من إيقاف العملية.

## هل remove يحذف كل شيء؟
يحذف فقط الإضافات التي سجلها السكربت ضمن state الخاص به. لا يحذف OpenCode أو إعدادات المستخدم أو الجلسات.

## هل تعمل إضافات V1 في V2؟
لا تفترض ذلك. دليل OpenCode الرسمي يذكر أن تنفيذات V1 لا تعمل في V2 وتحتاج port حقيقياً.

## كيف أضيف مصدراً لم يُحل؟
تحقق من صفحة المشروع الرسمية، ثم أضف `source` و`kind` و`status` إلى `config/plugins.json`، واختبر أولاً بـ `--dry-run`.
