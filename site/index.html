WHY IT EXISTS

V2 changed the rules.

OpenCode v2 uses a new plugin API. Package names and README claims are not enough. The manifest makes the source, version, review status, and reason visible before anything changes on a user's machine.

01

Doctor first

Stops when OpenCode is absent or not v2. The tool never installs or upgrades the host application.

02

Dry-run always

Preview the exact package operations before accepting them. Risky entries require an explicit flag.

03

Remove safely

Only plugins recorded in the script-owned state are removed. User configuration and sessions stay intact.
